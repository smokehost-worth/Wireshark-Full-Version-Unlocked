## Main Features
<a id="main-features"></a>

### Core Functionality
- **Real-time Data Capture** — Wireshark captures live data packets flowing through your network, allowing immediate analysis of network conditions.
- **Comprehensive Protocol Support** — It supports a variety of protocols, including TCP, ICMP, UDP, and more, enabling detailed examination of network interactions.
- **Detailed Network Layer Analysis** — Users can view IP addresses, DNS queries, and other essential information, aiding in troubleshooting and monitoring.
- **Export Options** — You can export captured data in multiple formats such as XML, PostScript, TXT, and CSV, making data sharing and analysis more accessible.
- **User-friendly Interface** — The interface is designed to present complex data in a neat and tidy manner, making it easier for users to interpret the information.

### Advanced Capabilities
- **Plugin Support** — Extend functionality with various plugins, allowing customization to meet specific analysis needs.
- **Offline Analysis** — Capture data in real-time and analyze it later offline, providing flexibility in how and when you work with the data.
- **Compatibility with Standards** — Wireshark is compatible with various standards, including BOOTP, DHCPv6, SCTP, and Kerberos, ensuring comprehensive network analysis across different environments.
- **Network Performance Monitoring** — Monitor performance metrics in real time to identify issues proactively and maintain optimal network efficiency.
